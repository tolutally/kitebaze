
### GET /pipelines — Get all pipelines
Returns data about all pipelines.
  param query:sort_by string ['id', 'update_time', 'add_time']  — The field to sort by. Supported fields: `id`, `update_time`, `add_time`.
  param query:sort_direction string ['asc', 'desc']  — The sorting direction. Supported values: `asc`, `desc`.
  param query:limit integer   — For pagination, the limit of entries to be returned. If not provided, 100 items will be returned. Please note that a maximum value of 500 is allowed.
  param query:cursor string   — For pagination, the marker (an opaque string value) representing the first item on the next page
  RESPONSE data:
  []id: integer — The ID of the pipeline
  []name: string — The name of the pipeline
  []order_nr: integer — Defines the order of pipelines. The pipeline with the lowest `order_nr` is considered the default.
  []is_deleted: boolean — Whether this pipeline is marked as deleted or not
  []is_deal_probability_enabled: boolean — Whether deal probability is disabled or enabled for this pipeline
  []add_time: string — The pipeline creation time
  []update_time: string — The pipeline update time
